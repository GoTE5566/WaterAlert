ศูนย์ข้อมูลน้ำจังหวัดนนทบุรี: ระดับน้ำรายสถานี กรมชลประทาน SWOC: อัตราระบายเขื่อนเจ้าพระยา และ C.2 ThaiWater: ระดับน้ำรายสถานี สำนักการระบายน้ำ กทม.: ระดับน้ำปากคลอง น้ำหนุน

หน้านี้ดึงข้อมูลสดอัตโนมัติไม่ได้ ต้องกรอกตัวเลขเอง เกณฑ์ปรับจากประกาศฤดูน้ำนี้ (อยุธยาและท้ายเขื่อน: 1,000 / 1,800 / 3,000 ลบ.ม./วิ ส่วนนนทบุรี: 2,200 / 3,000 / 3,500 โดยน้ำทะเลหนุนและน้ำป่าสักเพิ่มให้อีก 1 ระดับ) และเวลาเดินทางของน้ำเป็นค่าประมาณเพื่อเฝ้าระวัง ไม่ใช่ประกาศทางการ ให้ยึดประกาศของ สทนช. กรมชลประทาน และจังหวัดเป็นหลัก
